# 特戰造型

繁體中文 VALORANT 武器造型圖鑑網站。造型清單、圖片與展示影片從 [Valorant-API](https://valorant-api.com/) 載入；DailyVAL 僅作目錄參照，不使用其評分。

## 本機啟動

```sh
npm install
npm run dev
```

## 發布

```sh
npm run build
```

將 `dist/` 發布到任一靜態網站主機（例如 Vercel、Netlify 或 GitHub Pages）。需要訪客瀏覽器可連線至公開 Valorant-API；Google Fonts 目前提供字型，離線時會退回系統字型。

## 評分說明

各款造型顯示的 10 分制為可重複的資料代理估分：內容層級 45%、升級與變體等展示資料 35%、價格層級性價比 20%。此分數不是 DailyVAL 星等，也不是完整的人工作品視聽測試。Premate 社群榜單與 VALORANT 社群討論作為外部口碑脈絡參考；公開資料不足以支持逐款全量口碑平均，因此不宣稱它是玩家共識分。
